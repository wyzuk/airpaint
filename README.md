# AIRPAINT — Real-Time AI Hand Gesture Drawing Studio

AIRPAINT is a futuristic virtual drawing studio that allows users to draw directly over their live webcam feed using natural hand gestures.

## Features
- **1 Finger:** Pen / Draw Mode (smooth, low-latency drawing tracking the index fingertip)
- **2 Fingers:** Eraser Mode (index + middle finger)
- **3 Fingers:** Color Palette Mode (swipe left/right to select vibrant colors)
- **5 Fingers (Open Palm):** Neutral / Pause Mode
- **Closed Fist:** Idle Mode
- **Apple/macOS-inspired UI:** Frosted glass, translucent panels, refined controls
- **Export System:** Transparent PNG, background options, instant download

## Tech Stack
- MediaPipe Hand Landmarker (21-point tracking)
- HTML5 Canvas 2D + Vite
- Lucide Icons
